# Wishlist

These are features that would be nice to have, but are not in the current scope of the project.

- **Users to be able to contribute images of birds.** This would be a great way to build up a library of bird images, and also to engage the community.
- **Public events** Some users might want to create public events that anyone can join, instead of just private events that require an invite. This would be a great way to foster a sense of community and encourage more people to participate in birdwatching.
- **Invite by email** Currently, users can only invite friends by QR code, that is people have to be physically present to join an event. Allowing users to invite friends by email would make it easier for people to join events remotely.
- **Toggle birds that are 'visitors'** Some users might want to be able to toggle the display of more rare birds (s.k. 'visitors') in their bird lists, so they can focus on the more common birds if they want to.
- **Befriend other users** Users might want to be able to friend other users, so they can easily see each other's bird lists and activities.
  - **Leaderboards** A leaderboard feature could be added to show the friend with the most birds / best birdwatching streak / etc.
